## إعادة التوليد والتحقق

```
cd docs/requirements
python3 -I extract_docx.py <الملف.docx> > lawdesk-comprehensive-source.txt
python3 -I build_matrix.py            # يعيد توليد السجل
python3 -I build_matrix.py --check    # يفشل إن كان السجل قديمًا أو سطر مصدر بلا تغطية
```

العلامات `<badge>` في المصدر هي شارات المرحلة/الأولوية كما استخرجت من الوثيقة (المرحلة الأولى أولوية مرتفعة جدًا، إلخ).
