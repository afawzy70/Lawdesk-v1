## 3. اختبارات إضافية إلزامية

- وصول غير مصرح عبر API والملفات والتصدير والبحث والمساعد لكل دور وكل نطاق.
- إضافة حكم أو درجة لا تستبدل نتائج الطلبات والدفوع السابقة.
- الهيكل التنظيمي التاريخي بعد تعديل الإعدادات (اللقطة ثابتة).
- ردود متعددة وجزئية وغير مكتملة وتصعيد.
- تسوية أو إغلاق قضية مرتبطة لا تغلق القضية.
- فشل OCR أو المزود الذكي ومصدر غير كافٍ ← رسالة امتناع.
- نص خبيث داخل مستند مرفوع يُعامل بيانات لا تعليمات.
- ترحيل ورجوع واستعادة على بيانات تمثل UAT.
- تزامن: كتابة متزامنة بقفل `version`، منع تكرار الأحداث والتنبيهات (`dedupe_key`).
- RTL، موبايل، متصفحات (Chromium وFirefox وWebKit)، أداء، تصدير بصحة المبالغ دون تضاعف.
- تغطية أمامية 90% فروع، وتغطية خلفية لا تنقص.

## 4. التقارير والتسليم

تقرير بالعربية بعد كل مرحلة (المتطلبات المكتملة بمعرفاتها وأدلتها، المتبقي والمعطل، PRs وSHA ونتائج الاختبار، رابط UAT وخطوات التقييم، تغييرات النموذج، القرارات). في النهاية: دليل المستخدم، التوثيق الفني، مخطط البيانات، الصلاحيات، إعدادات المواعيد، التشغيل والنسخ الاحتياطي والاستعادة، التكاملات، إعداد المساعد.
لا يُعلن اكتمال المشروع إلا بمطابقة الأقسام الـ37 في السجل، وتشغيل الوظائف مترابطة، واجتياز S1–S16، والإفصاح عن القيود.
