## تشغيل المعاينة

افتح `docs/design/prototype/index.html` في متصفح، أو استخدم رابط النسخة المنشورة المرسل مع التقرير. الشاشات بالتتابع: اللوحة ← تسجيل القضية ← الملخص والخط الزمني ← الطلبات ← الدفوع ← الأدلة ← طلبات الإفادة ← الجلسات والتأجيل ← تسجيل الحكم (نتيجة كل طلب وموقف كل دفع، تفاعلي) ← الدرجة التالية ← المواعيد والتنفيذ (مسار اعتماد الميعاد) ← المكتبة والسوابق ← المخاطر ← الصلاحيات (اختيار دور تفاعلي).
المعاينة لا تتصل بالخادم، وكل أسمائها وأرقامها وأحكامها اصطناعية. المدة في شاشة المواعيد «قاعدة توضيحية غير قانونية».
