# LD-DOC-02 — قاموس مصطلحات المجال

| العربية | الاسم التقني | المعنى في LawDesk |
|---------|--------------|-------------------|
| الهيئة | authority | الجهة الحكومية صاحبة النظام؛ طرف فعلي في الدعوى (اسمها من الإعداد `lawdesk.authority.name`) |
| الإدارة القانونية | legal department | مستخدمو الأدوار القانونية؛ المرجع في اختيار العضو المختص |
| العضو المختص / البديل | primary / alternate member | المسؤول عن القضية وبديله؛ لهما صلاحية تعديل القضية |
| رقم القضية الداخلي | `reference_no` | مرجع يولده النظام LD-YYYY-NNNNN لا يتغير |
| الرقم الآلي (القضائي) | `automated_no` | رقم يدخله المستخدم، نص، ثابت عبر الدرجات |
| رقم القضية بالمحكمة | `court_case_number` + `court_case_year` | لكل درجة؛ تُحفظ أرقام الدرجات السابقة |
| طبيعة النزاع | `case_type` | إدارية، مدنية، تجارية، عمالية، جزائية، دستورية، أخرى… |
| المسار / الدرجة | `proceeding.stage` | أول درجة، استئناف، تمييز، دستورية، تنفيذ، تظلم |
| الدرجة (سجل) | proceeding | سجل مستقل لكل مسار قضائي مرتبط بالقضية |
| الطلب | claim | ما يطلبه خصم من المحكمة؛ له رقم تسلسلي ونسخ تعديل ونتيجة لكل حكم |
| نتيجة الطلب | claim_result | قرار المحكمة في طلب بعينه ضمن حكم بعينه |
| الدفع | defense | دفع شكلي/إجرائي/موضوعي تتمسك به الهيئة |
| موقف المحكمة من الدفع | defense_position | قرار المحكمة في دفع بعينه ضمن حكم بعينه |
| الواقعة | case_fact | واقعة تُثبت بمستند؛ تربط الأدلة بالدفوع |
| الدليل / المستند المؤيد | evidence_item | مستند له دور (مؤيد، من الخصم، محل نزاع، مطلوب، غير متوافر، مكمل) |
| طلب الإفادة | info_request | كتاب داخلي لإدارة بطلب إفادة أو مستندات؛ له ردود متعددة |
| الجهة الإدارية المعنية | org involvement | قطاع ← إدارة ← قسم مرتبط بالقضية (رئيسية/مساندة) |
| الجلسة | hearing | جلسة محكمة أو خبراء أو تحقيق أو إجراء؛ التأجيل ينشئ جلسة جديدة |
| الميعاد القانوني | deadline | ميعاد طعن أو مذكرة أو تنفيذ؛ التاريخ المحسوب «مقترح» حتى يعتمده مختص |
| القضية المرتبطة | case_link | ارتباط موضوعي أو طلب ضم أو قرار ضم أو إحالة |
| الحكم | judgment | حكم في درجة؛ يحفظ المنطوق والأسباب والمبالغ ونتائج الطلبات والدفوع |
| تنفيذ الحكم | enforcement | ملف إجراءات تنفيذ حكم بعينه |
| المبدأ المستخلص | library_principle | مبدأ قانوني مستخلص من حكم في المكتبة، مفصول عن نص الحكم |
| الأثر المالي | financial_impact | تقدير الأثر على الهيئة (نعم/لا + مبلغ) |
| القيمة المطالب بها | claimed_amount | ما يطالب به الخصم |
| الخسارة المحتملة | potential_loss | تقدير ضمن إصدار تقييم المخاطر، لا توقع قضائي |
| المخاطر القانونية | risk_assessment | تقييم بعشرة عناصر ومستوى (منخفضة، متوسطة، مرتفعة، مرتفعة جدًا) مع أسباب |
| التسوية | settlement | عرض تسوية أو تنازل أو صلح؛ لا تنهي القضية بمجرد التسجيل |
| التكليف | directive | قرار أو تكليف إداري يتعلق بقضية |
| التوقيت | Asia/Kuwait | UTC+3 دون توقيت صيفي؛ اللحظات `timestamptz`، التواريخ القانونية `date` |
| العملة | KWD | دينار كويتي، `numeric(15,3)` |
