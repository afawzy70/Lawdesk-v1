## ما لم يُنفَّذ أو يعتمد على غيره

- **البحث في الطلبات والدفوع (28-004, 28-005)**: جدولا `claim`/`defense` من WP2 غير مدموجين؛ يُضاف مصدرهما إلى `SearchSpecs` بعد دمج WP2. **منطوق الأحكام (28-006)** يبحث الآن في `judgment.summary` فقط حتى يضيف WP2 `operative_text`. المبادئ تُبحث ضمن أحكام المكتبة.
- **البحث داخل المستندات (28-013)**: بيانات المستند الوصفية فقط؛ النص بعد OCR يأتي مع WP5.
- **الأداء**: الفهرسة محسوبة لحظة الاستعلام (لا فهرس مخزّن للجداول الحالية)؛ القياس على 50 ألف قضية ضمن حزمة أداء المرحلة 8. جداول WP9 الجديدة لها `tsvector` مولَّد وفهرس GIN.
- **إنذار الإغلاق بتسويات غير مكتملة الموافقة (LD-DOC-05 §1)** لم يُضف إلى تغيير حالة القضية؛ الاعتماد لا يغلق شيئًا آليًا (مُختبَر).
- نصوص نماذج فعلية: لم تُزرع ولم تُولَّد؛ يدخلها مديرو النماذج. التسجيل التدقيقي لا يعرض مبالغ التسوية (لا تُكتب فيه أصلًا).
- مقتضى شكلي: اختبارات الواجهة كُتبت أولًا ونُفِّذت حمراء بحجب مصادر الشاشات، ثم أُعيدت.
