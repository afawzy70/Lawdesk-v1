# LawDesk v1

Legal case management platform: Java 21 / Spring Boot API, React + TypeScript web app, PostgreSQL, deployed with Docker Compose.

- Owner-approved delivery strategy (implementation, QA, security, performance, release): [docs/governance/LAWDESK-DELIVERY-STRATEGY.md](docs/governance/LAWDESK-DELIVERY-STRATEGY.md)
- Product and QA baseline: [README-QA-BASELINE.md](README-QA-BASELINE.md), `product/`, `qa/`, `architecture/`
- Current delivery status and blockers: [docs/delivery/PHASE-1-CHECKPOINT.md](docs/delivery/PHASE-1-CHECKPOINT.md)
