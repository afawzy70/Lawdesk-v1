# Modern Chambers fonts

DM Sans, Cairo and IBM Plex Sans Arabic were downloaded on 2026-10-25 from the official Google Fonts CSS endpoint (`fonts.googleapis.com/css2`) and its `fonts.gstatic.com` WOFF2 URLs. Each font's SIL Open Font License is included alongside the font files. Only the Arabic and Latin subsets used by LawDesk were retained. CSS references local files so the application does not contact Google Fonts at runtime.
